# Human-Written Banking System Code

This repository contains the human-written implementation of the banking system used as the baseline in our comparative security study.

## Overview
- **System:** Core banking operations (account creation, deposits, withdrawals, transfers).
- **Source:** Written manually by a developer.
- **Purpose:** Evaluated using the same security pipeline (`AI-Generated-Code-Security-Evaluator`) to benchmark security vulnerabilities against the AI-generated version.
